# humanized

<img src="./logo.png" alt="humanized" width="360">

Скилл humanized помогает писать, редактировать и проверять посты, статьи, рабочие письма и резюме. Он подстраивает правку под читателя и жанр, убирает общие фразы и сохраняет голос автора, факты и уместную типографику. В режиме проверки объясняет, какие места звучат шаблонно и почему, сохраняя исходный текст. Формат Agent Skills поддерживают Claude Code, Codex и другие агенты.

## Установка в Claude Code

```bash
claude plugin marketplace add roovwhite/turbo-bullfinch
claude plugin install humanized@turbo-bullfinch
```

## Установка в Codex

Клонируйте репозиторий и скопируйте каталог скилла целиком. Команды ниже выполняются из корня клона и устанавливают скилл для текущего пользователя:

```bash
mkdir -p ~/.agents/skills
cp -R plugins/humanized/skills/humanized ~/.agents/skills/
```

Если `~/.agents/skills/humanized` уже существует, сначала удалите или обновите его вручную, чтобы не получить вложенный каталог. Для установки только в текущий проект вместо `~/.agents/skills/` используйте `.agents/skills/` в корне проекта. Начните новую сессию Codex; вызвать скилл можно через `$humanized`.

## Другие агенты

Скопируйте каталог `plugins/humanized/skills/humanized` целиком в каталог скиллов агента согласно его документации. Внутри находятся `SKILL.md` и `lint.py`; они не зависят от переменных Claude. Агентам без поддержки Agent Skills можно передать содержимое `SKILL.md` как инструкции, но автоматическое обнаружение и запуск линтера зависят от возможностей среды. Русские примеры ориентированы на русскоязычные тексты; скилл также применяет общие принципы к другим языкам.

## Режим проверки, линтер и тесты

Чтобы получить разбор без правок, добавьте к запросу «только проверь». При редактировании скилл оставляет удачные формулировки и сохраняет цитаты.

Линтер находит характерные служебные фразы на границах текста и метки `utm_source=openai` и `utm_source=chatgpt.com` в ссылках. Он печатает номер строки, правило и фрагмент и возвращает 1 при совпадении. Нужен Python 3.

```bash
python3 plugins/humanized/skills/humanized/lint.py draft.md
```

Для площадок, где требуются прямые кавычки и ASCII-дефисы, добавьте `--ascii-punctuation`. По умолчанию тире и типографские кавычки сохраняются.

В [evals/README.md](evals/README.md) описаны регрессионные сценарии и слепое сравнение версий скилла.

Идея режима проверки, линтера и тестов подсмотрена у [smixs/humanizer-ru](https://github.com/smixs/humanizer-ru).
