# humanized

Скилл humanized помогает писать и править тексты так, чтобы они читались как написанные человеком: посты, статьи, рабочие письма, резюме. Он использует формат Agent Skills и подходит для Claude Code, Codex и других агентов с поддержкой этого формата. Правила опираются на эссе русской Википедии "Википедия:Признаки сгенерированности текста" (ВП:ПРГЕН).

## Установка в Claude Code

```bash
claude plugin marketplace add roovwhite/turbo-bullfinch
claude plugin install humanized@turbo-bullfinch
```

## Установка в Codex

Клонируйте репозиторий и скопируйте каталог скилла целиком. Команды ниже выполняются из корня клона и устанавливают скилл для текущего пользователя:

```bash
mkdir -p ~/.agents/skills
cp -R plugins/humanized/skills/humanized ~/.agents/skills/
```

Если `~/.agents/skills/humanized` уже существует, сначала удалите или обновите его вручную, чтобы не получить вложенный каталог. Для установки только в текущий проект вместо `~/.agents/skills/` используйте `.agents/skills/` в корне проекта. Начните новую сессию Codex; вызвать скилл можно через `$humanized`.

## Другие агенты

Скопируйте каталог `plugins/humanized/skills/humanized` целиком в каталог скиллов агента согласно его документации. Внутри находятся `SKILL.md` и `lint.py`; они не зависят от переменных Claude. Агентам без поддержки Agent Skills можно передать содержимое `SKILL.md` как инструкции, но автоматическое обнаружение и запуск линтера зависят от возможностей среды. Русские примеры ориентированы на русскоязычные тексты; скилл также применяет общие принципы к другим языкам.

## Режим проверки, линтер и тесты

Если попросить только проверить текст ("это похоже на нейросеть?", "только проверь", "не правь"), скилл его не переписывает. Он отвечает вердиктом из трёх ступеней (чистый, сомнительный, похоже на сгенерированный) и списком улик, где у каждой короткая цитата и название паттерна из SKILL.md. При обычной правке текст без заметных тэлов возвращается как есть.

Линтер `plugins/humanized/skills/humanized/lint.py` ловит механические нарушения, которые модель пропускает: длинное и среднее тире, ёлочки и фигурные кавычки, utm-метки ChatGPT в ссылках, фразы чат-бота в начале и в конце текста, эмодзи в заголовках и пунктах списков. Он ничего не исправляет, а печатает номер строки, правило и фрагмент и возвращает 1, если что-то нашёл. Для запуска нужны Python 3 и доступ к командной строке. При их отсутствии скилл предлагает ручную проверку; замечания линтера оцениваются с учётом задачи и защищённых фрагментов.

```bash
python3 plugins/humanized/skills/humanized/lint.py draft.md
```

В `plugins/humanized/evals/` лежат 12 сценариев: входной текст и проверки простыми фразами. Как прогнать их вручную, описано в `plugins/humanized/evals/README.md`.

Идея режима проверки, линтера и тестов подсмотрена у [smixs/humanizer-ru](https://github.com/smixs/humanizer-ru).
